# Compatibility And Advanced Maturity Criteria

The historical V3-V10 labels remain in file paths, tool names, scripts, tests, and compatibility docs. They are no longer the public product framing.

Public docs should use these names instead:

- Advanced maturity criteria.
- Standards intelligence.
- Local governance criteria.
- Strategic planning criteria.
- Governance automation.
- Operating-model evals.
- Productization boundary evals.
- Repo-quality evals.

## Compatibility Rule

Do not rename existing `docs/v*-*.md` files, tool names, script names, or tests unless a separate migration explicitly covers consumers. This docs site changes the public language and navigation without breaking identifiers.
